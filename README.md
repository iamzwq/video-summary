# 视频总结 Video Summary

油猴脚本：在 B站 / YouTube 视频页的工具栏添加「视频总结」按钮，一键获取视频字幕，并用 AI 生成中文总结。

## 安装

1. 在浏览器中安装油猴扩展 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey）。
2. 点击安装最新版脚本：**[video-summary.user.js](https://github.com/iamzwq/video-summary/releases/latest/download/video-summary.user.js)**，在弹出的油猴安装页点击「安装」即可。
   - 也可以前往 [Releases](https://github.com/iamzwq/video-summary/releases) 页面，在对应版本的 Assets 中点击 `video-summary.user.js`。
3. 如果点击后没有弹出安装页，而是直接下载了文件，可任选一种方式手动添加：
   - 把 `video-summary.user.js` 文件直接拖进浏览器窗口，在弹出的安装页点击「安装」；
   - 或打开 Tampermonkey 管理面板 →「实用工具」→「导入」，选择该文件；
   - 或在 Tampermonkey 中「添加新脚本」，将文件内容全部粘贴进去并保存。
4. 首次生成总结时，如果 Tampermonkey 弹出跨域访问确认，请选择「总是允许」。

> 使用 Chrome / Edge 时，如果脚本不生效，请在扩展管理页为 Tampermonkey 打开「允许用户脚本」（或开发者模式）。
>
> 更新脚本：重新点击上面的安装链接，即可覆盖安装最新版本。

## 支持的页面

- B站视频页：`www.bilibili.com/video/...`（不支持番剧页）
- YouTube 视频页：`www.youtube.com/watch?v=...`

## 使用

1. 打开视频页，点击视频下方工具栏中的「视频总结」按钮。
   - 也可以点击浏览器工具栏的油猴图标 →「生成视频总结」。
2. 首次使用会弹出设置面板，填写模型接口信息后点击「保存」，即自动开始生成总结。
3. 总结会显示在页面右侧的浮动面板中：
   - 点击总结里的时间戳（如 `[03:25]`）可以跳转到视频对应位置；
   - 顶部下拉框可以切换字幕轨道；
   - 右上角按钮依次为：重新生成、复制 Markdown、下载字幕（SRT）、设置、关闭；
   - 生成过程中可以点击「停止」中断；
   - 面板标题栏可以拖动。

### 字幕选择规则

- 优先使用 UP 主 / 作者**手动上传的字幕**，没有时使用**自动生成的字幕**。
- 同类字幕中优先选择**视频原始语言**，其次中文、英文。
- 无论字幕是什么语言，总结都输出为**简体中文**。

## 设置

点击面板右上角的设置按钮，或油猴图标 →「视频总结设置」打开。

| 设置项 | 说明 |
|---|---|
| Base URL | OpenAI 兼容接口地址，例如 `https://api.openai.com/v1`、`https://api.deepseek.com/v1` |
| API Key | 接口密钥（本地 Ollama 等服务可留空） |
| 模型 | 模型名称，例如 `gpt-4o-mini`、`deepseek-v4.1-flash` |
| Temperature | 0 ~ 2，默认 0.3 |
| 深度思考 | 关闭（默认）/ 开启 / 自动 |
| 思考程度 | minimal（默认）/ low / medium / high |
| 分段阈值 | 字幕过长时分段总结的阈值，默认 12000 |
| 缓存条数 | 最多缓存的总结条数，默认 20，设为 0 则不缓存 |
| 系统提示词 | 可自定义总结格式，支持一键恢复默认 |

填写完成后可以点击「测试连接」确认接口可用。

> - 总结视频一般不需要深度思考，保持「关闭」速度更快、更省 token。
> - 如果所用的模型服务不支持「深度思考 / 思考程度」参数而报错，请换用支持的模型。
> - API Key 只保存在本地油猴脚本存储中。

## 常见问题

**看不到「视频总结」按钮？**
等页面加载完成后再看；如果站点改版导致按钮无法显示，可以通过油猴图标 →「生成视频总结」使用。

**B站提示没有可用字幕？**
B站的 AI 字幕需要登录后才能获取，请先登录 B站 再试。

**YouTube 获取字幕失败？**
先手动打开一次播放器的字幕（CC）按钮，再点击「视频总结」重试。

**视频没有任何字幕？**
本脚本基于字幕生成总结，没有字幕的视频无法总结。

**总结结果会保存吗？**
默认缓存最近 20 条总结（可在设置中修改「缓存条数」，设为 0 则不缓存），再次打开同一视频会直接显示；点击「重新生成」可重新总结。面板右上角的下载按钮可将当前选中的字幕轨道导出为 SRT 文件。
